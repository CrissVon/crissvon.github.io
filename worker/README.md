# Проксі тривог (Cloudflare Worker)

Сайт на GitHub Pages не може напряму читати `siren.pp.ua` (браузер блокує через CORS),
тому між ними стоїть маленький Worker: бере статус для Києва, чистить дані та кешує на 20 с.

## Розгортання (≈5 хвилин, безкоштовно)

1. Зареєструйся на <https://dash.cloudflare.com> (картка не потрібна).
2. **Workers & Pages** → **Create** → **Create Worker** → назви, наприклад, `kyiv-alert` → **Deploy**.
3. **Edit code** → видали все, встав вміст `alert-proxy.js` → **Deploy**.
4. Скопіюй адресу Worker (щось на кшталт `https://kyiv-alert.<твій-акаунт>.workers.dev`).
5. У `js/app.js` встав її в `CONFIG.ALERT_URL` і запуш у GitHub.
6. (Рекомендовано) **Settings → Variables** → додай `ALLOWED_ORIGIN` = `https://crissvon.github.io`,
   щоб Worker відповідав тільки твоєму сайту.

Перевірка: відкрий адресу Worker у браузері. Побачиш `{"ok":true,"alert":null}`
(або дані про тривогу, якщо вона є).

## Перевірка вигляду без реальної тривоги

Додай до адреси сайту `?alert=red` або `?alert=yellow` (і за бажанням `&alerttext=Будь-який текст`).

## Якщо джерело зникне

Код не прив'язаний до `siren.pp.ua`: достатньо змінної `UPSTREAM` (інша адреса з таким самим форматом)
і, за потреби, `UPSTREAM_AUTH` з ключем. Офіційне API `api.ukrainealarm.com` віддає той самий формат,
але потребує ключа (заявка через форму на їхньому сайті).

## Що показується на сайті

| Рівень | Колір    | Приклад тексту  |
|--------|----------|-----------------|
| Red    | червоний | Ракетна загроза |
| Yellow | жовтий   | Дронова загроза |

Якщо дані не оновлювались понад 3 хвилини (Worker чи джерело недоступні), сайт **ховає** стан тривоги,
а не показує «все спокійно»: це не офіційне джерело сповіщень.
